# 📚 Roadmap

## Phase 1 – Recursion Mindset Reset (No Math, No Strings)

### 🎯 Goal
Understand how recursion actually works.

### Questions

- [ ] Print `"Hello"` exactly 5 times using recursion.
- [ ] Print numbers from 1 to 5 without parameters.
- [ ] Print numbers from 5 to 1.
- [ ] Print `"Before Call"` and `"After Call"` to observe recursion flow.
- [ ] Print numbers from 1 to n after the recursive call.
- [ ] Print numbers from 1 to n before the recursive call.
- [ ] Print `"Start"` only once and `"End"` only once.
- [ ] Print the current value of `n` during each recursive call.
- [ ] Stop recursion only when `n == 0`.
- [ ] Dry-run recursion manually and write the call stack.

# 💡 Recommended Workflow

For every problem:

- Understand the problem.
- Identify the Base Case.
- Identify the Recursive Case.
- Dry-run on paper.
- Write the recursive solution.
- Analyze Time Complexity.
- Analyze Space Complexity.
- Optimize if possible.
